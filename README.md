# Georgia Rachel — The Pond

A separate personal portfolio adapted from [BrewedOps portfolio-template](https://github.com/brewed-ops/portfolio-template). Original profile rail, responsive shell, bento layout and Three.js project carousel are retained. Georgia’s paper/forest palette and procedural koi replace the contour background.

## Develop

npm ci
npm run dev
npm run build

GitHub Pages base: /georgia-rachel-pond-portfolio/. Hash routing supports direct links. `src` owns the template shell and dashboard. `public/archive` contains isolated original portfolio sections to preserve the detailed layouts, native dialogs, live project previews, contribution calendar, certificate redactions, résumé, testimonials and retained-koi fishing engine. Only masked credential images are included; no raw certificate PDFs or diploma photo. GitHub data reads the existing hourly public mirror.
